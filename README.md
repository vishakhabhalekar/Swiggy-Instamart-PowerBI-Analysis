# 🛒 Swiggy Instamart Sales & Operations Analysis – Power BI

##  About the Project

This is a Power BI project based on **Swiggy Instamart order data**.

I created this project to understand how customers place orders, which products perform well, how orders are delivered, and where operational problems occur.

I cleaned and transformed the raw data using **Power Query** and then created an interactive dashboard using **Power BI and DAX**.

---

## 🎯 Project Objectives

The main goals of this project are:

* Understand overall sales and order performance
* Analyze customer behavior
* Find top-performing products and categories
* Analyze new and repeat customers
* Understand different order statuses
* Analyze delivery time and customer ratings
* Identify useful business insights from the data

---

## 📊 Dashboard

The dashboard is divided into three main pages:

### 1. Executive Overview

This page gives a quick summary of the overall business performance.

**Main KPIs:**

* Total Customers
* Total Orders
* Total Sales
* Average Order Value
* Average Customer Rating
* Top Product

### 2. Customers & Products

This page focuses on customer and product analysis.

It includes:

* New vs Repeat Customers
* Top Products
* Product Categories
* Customer behavior
* Product performance

### 3. Operations & Delivery

This page focuses on order and delivery performance.

It includes:

* Delivered Orders
* Cancelled Orders
* Pending Orders
* Returned Orders
* Delivery Time
* Customer Ratings
* Delivery Partner analysis

## 🧹 Data Cleaning

Before creating the dashboard, I cleaned and prepared the raw dataset using **Power Query**.

Some of the steps included:

* Removed duplicate Order IDs
* Checked missing values
* Corrected data types
* Cleaned date fields
* Checked blank and invalid values
* Prepared the data for analysis

## 📈 Key Insights

From the dashboard, I was able to understand:

Based on the analysis, some possible actions are:

* Focus more on high-performing products
